Formatta

A tool that builds, checks and exports structured documents from your own sources. AI only where meaning is needed.

Role: product and architecture, lead developer · Cross-functional team · Stack: Python, FastAPI, HTMX, SQLite, local LLMs

The problem

FAQs, use cases and release notes are written the same way again and again: collect facts from several files, fit them into a structure, find what is missing, format, and redo it for another format. A chat model writes a text once, but it doesn’t keep sources, doesn’t check against requirements and fills gaps with inventions.

What it does

  • Assemble a document from your sources by a template. Missing facts become visible gaps, not guesses.
  • Check an existing document: structure by code, completeness and terms by the model.
  • Convert to DOCX, PDF, HTML or Markdown without rewriting the content.

Key decisions

A neutral document model

Problem
Edits, checks and exports all need the same document.
Choice
A format-neutral tree instead of editing DOCX: one editor, one check path, several renderers.

Code where it can be exact

Problem
Some checks must be reproducible, others need understanding.
Choice
Structure is checked by code; completeness, terms and contradictions by the model.

Missing facts stay visible

Problem
A model fills gaps with plausible text.
Choice
The system works only from your sources and shows what is missing.
